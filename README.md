# 3X-UI Telegram Management Bot

Синхроннный Telegram bot для автоматизации регистрации клиентов на сервере в 3x-ui

## Основные возможности

* Регистрация пользователей: при команде /start автоматически регистрирует клиента 3x-ui и привязывает все активные inbounds.
* Привязка протоколов: команда /new_inbounds обновляет список подключений для пользователя.
* Мониторинг сервера: каждые 10 секунд проверяются изменения на сервере. При изменении бот отправляет рассылку все зарегистрированным пользователям.
* Логирование: Вся работа приложения пишется в консоль и файл с ротацией и сжатием при помощи 'loguru'.


## Стек технологий

* Язык: Python 3.13+
* Сетевые запросы: 'requests'
* Логирование: 'loguru'
* Хранилище: JSON (`users.json`, `inbound_ids.json`, `server_options.json`)
